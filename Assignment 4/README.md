
# My Creative Portfolio

## About the Project

This is my personal portfolio website created using HTML
and CSS as part of Assignment 05.

It contains my introduction, skills, education,
projects and contact information.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Variables
- Flexbox
- CSS Grid

## Design Choices

I selected a dark navy, orange and cream colour palette
to give my portfolio a modern and professional look.

I used Poppins for headings because it looks bold
and attractive. Nunito is used for body text because
it is clean and easy to read.

CSS variables are used to maintain consistent colours,
font sizes and spacing throughout the website.

Hover effects are added to buttons and project cards
to make the website more interactive.

The layout is also responsive so that it works
on mobile phones and desktop screens.

## Features

- Navigation bar with internal links
- About and skills sections
- Education details
- Project cards
- Contact section
- Hover effects
- Responsive layout
- External CSS stylesheet
