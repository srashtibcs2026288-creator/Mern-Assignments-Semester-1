
# Assignment 06 – Bloom & Root

## Business Introduction

Bloom & Root is a modern indoor plant shop.
It offers indoor plants, decorative pots and plant care
guidance for people who love greenery.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Positioning
- Background Images
- Inline-block
- Box Model

## Website Sections

1. Home / Hero Section
2. About Us
3. Our Services
4. Plant Gallery
5. Special Offer
6. Contact Form
7. Footer

## Design Choices

I selected a nature-inspired colour palette using
forest green, sage green, cream and terracotta.

I used Playfair Display for headings because it gives
the website an elegant appearance. DM Sans is used
for body text because it is clean and readable.

Three different service card designs are created
using different borders, backgrounds, border-radius
and shadows.

The hero section uses a background image with a dark
overlay. Positioning and z-index are used to place
the text above the overlay.

Normal document flow and inline-block are used
instead of Flexbox and Grid.

## Features

- Attractive hero section
- Background image and overlay
- Three different service cards
- Image gallery
- Contact form
- Hover effects
- Responsive design
- External CSS stylesheet
